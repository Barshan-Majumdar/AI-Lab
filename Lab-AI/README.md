## 📖 About

**Lab-AI** contains code and notebooks for AI laboratory work — from classic search algorithms to machine learning models. Each experiment is self-contained, documented, and easy to run, so it can be used for learning, revision, or as a starting point for your own projects.

## ✨ Highlights

- Clean, commented implementations of core AI concepts
- One folder per experiment, each with its own code and sample output
- Beginner-friendly and easy to run locally or in Google Colab

## 🗂️ Repository Structure


## 🚀 Getting Started

### Prerequisites

- Python 3.9 or higher
- pip

### Installation

```bash
# Clone the repository
git clone https://github.com/RimiD162/Lab-AI.git
cd Lab-AI

# (Optional) create a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### Running an Experiment

```bash
cd Experiment-01
python main.py
```

For notebooks:

```bash
jupyter notebook
```
